# GL Aluminum and Glass Installation Services

A modern, responsive website for GL Aluminum and Glass Installation Services built with Next.js 14, Tailwind CSS, and TypeScript.

## Features

- **Modern Design**: Minimalist and professional design with white, black/dark gray, and blue accents
- **Responsive**: Mobile-first design that works on all devices
- **SEO Friendly**: Optimized for search engines
- **Fast**: Built with Next.js 14 App Router for optimal performance
- **Reusable Components**: Clean component architecture

## Sections

- Hero section with business introduction
- Services showcase (Aluminum windows, Sliding doors, Awning windows, Glass installation)
- Projects gallery with filtering
- About section
- Contact form with Google Maps embed
- Sticky navigation and footer

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- React 19

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

```bash
npm run build
```

## Deploy

Deploy to Vercel, Netlify, or any static hosting service.
